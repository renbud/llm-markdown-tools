# Security Policy

## Supported versions

The project currently supports the latest released version on the main branch.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues or discussions.

Instead, contact the maintainer privately using the project email address or a private channel agreed with the maintainer.

Please include:

- a description of the issue
- affected version
- reproduction steps if available
- severity assessment if known
- any suggested fix or mitigation

## Disclosure process

We will review and respond as quickly as possible. We appreciate responsible disclosure and will work with you to understand and resolve the issue.
